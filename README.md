# Brick competitor images

1. Upload everything in this folder to a new **public** GitHub repo (keep the folder structure,
   including `.github/workflows/fetch-images.yml`).
2. Open the repo's **Actions** tab, choose **Fetch product images**, click **Run workflow**.
3. Wait for the green check (about 5-15 minutes). An `images/` folder appears, one subfolder per product.
4. Send the repo link back to Claude.

Edit `products.csv` to add or change product pages (format: `slug,url`).
